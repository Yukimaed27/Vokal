## Método y alcance

Para lesen, Duden genérico no recuperó el verbo de lectura: se usa Netzverb para corroborar categoría/formas, junto con Langenscheidt para la equivalencia.
Un script recuperó y almacenó páginas; no aprobó fichas. Se contrastaron significados y se siguieron homógrafos/reenvíos.
Se verificaron nominalizaciones separadas (Heute, Nichts, cifras), artículos, participios, adverbios y partículas.
PONS en dirección inversa corrobora nada→Nichts y dos→Zwei con categoría nominal; no se usa una mera coincidencia de pronombre/numeral.
Se limita cada ficha a un sentido; se descartan ejemplos/definiciones no acotados. Los22 anteriores mantienen su evidencia ya registrada.
No se certifican paradigmas completos, todos los sentidos, pronunciación ni niveles MCER. humanReviewed permanece false.
Los cinco casos pendientes de los dos lotes no se convierten en aprobados para ajustar una cifra.
